
# Residenza Ponte d'Oro - 5 APK Badge Telefono

Questo repo compila automaticamente 5 APK diversi, uno per dipendente.

## Come ottenere gli APK (2 minuti):

1. Crea repo vuoto su GitHub (es. ponte-oro-badge)
2. Carica tutti i file di questa cartella sul repo (Upload files)
3. Vai su Actions > vedrai "Build 5 APK Ponte d'Oro" in esecuzione
4. Dopo 3 minuti, scarica Artifacts > apk-ponte-oro-5-dipendenti.zip
5. Dentro trovi:
   - app-mariaRossi-debug.apk (Maria Rossi 100001)
   - app-lucaBianchi-debug.apk (Luca 100002)
   - app-giuliaVerdi-debug.apk (100003)
   - app-marcoNeri-debug.apk (100004)
   - app-annaGialli-debug.apk (100005)

6. Mandi ogni APK su WhatsApp al dipendente giusto. Installano.

Ogni APK contiene già ID univoco PONTEORO-10000X e logo Ponte d'Oro.

## Come funziona sul tablet Via Sardegna 10:

Tablet in reception con Kiosk Ponte d'Oro attivo > dipendente avvicina telefono > tablet legge ID via NFC HCE > chiede PIN > timbra.
